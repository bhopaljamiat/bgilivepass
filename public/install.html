BGI Live Pass — Install on PC

Download the app and get a direct icon on your Windows/Mac desktop.

Easiest way: you will see the “Install App” button at the bottom-right of the screen — click it and confirm. The full app will be installed on your PC. (Use the Chrome or Edge browser)

Windows PC CHROME / EDGE

  1. Open the site in Google Chrome or Microsoft Edge.
  2. Click the “Install App” button at the bottom-right — or click the install icon (⊕ / monitor icon) in the browser's address bar.
  3. Click Install in the confirmation dialog.
  4. A “BGI Live Pass” icon will appear on your Desktop and Start Menu — it opens like a regular app in its own full-screen window.
Tip: After installing, the app also opens offline — the login page and UI load instantly; internet is only needed for live data.

What you get

✓Desktop icon + Start Menu shortcut — no need to type the URL in the browser every day.
✓Its own separate window — never mixes with your browser tabs.
✓Fast loading — the app shell opens instantly from cache.
✓Guard Scanner, Master Admin, Sub Admin — direct access from the Start Menu.

Also on mobile ANDROID / IPHONE

  1. Android (Chrome): tap the “Install App” button at the bottom-right, or Chrome menu (⋮) → “Add to Home screen”.
  2. iPhone (Safari): Share button ⎋ → “Add to Home Screen”.
